# NordEditor

A lightweight, dark-themed code editor with syntax highlighting for Python,
JavaScript, HTML, CSS, JSON, and Bash.

## Install (Python users)
pip install nordeditor

## Download (everyone else)
Grab the latest binary from the [Releases](../../releases) page.

## Features
- Multiple tabs
- Syntax highlighting (Python, JS, HTML, CSS, JSON, Bash)
- Find & Replace
- Line numbers
- UTF-8 clipboard handling

## Run from source
pip install PyQt5
python nordeditor.py
